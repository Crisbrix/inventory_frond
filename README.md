# Inventory Frontend - Angular Dashboard

Dashboard moderno y minimalista para sistema de inventario construido con Angular.

## Características

- Diseño minimalista con colores naranja y blanco
- Responsive design
- Componentes modulares con tarjetas
- Angular 17 con componentes standalone

## Requisitos

- Node.js 18+ 
- npm o yarn

## Instalación

```bash
cd inventory_frond
npm install
```

## Ejecutar

```bash
npm start
```

La aplicación estará disponible en `http://localhost:4200`
